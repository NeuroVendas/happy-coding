Admin inicial

Este recurso só existe para vincular o primeiro administrador. Exige conta autenticada, MFA/TOTP em AAL2 e o código único fornecido pelo responsável do projeto. Depois que um admin existe, o bootstrap fecha.

Excluir minha conta

Isso remove sua conta de autenticação. Dados ligados por chaves com exclusão em cascata também podem ser removidos. Tokens de acesso já emitidos podem continuar válidos até expirarem, por isso saia do app em outros dispositivos também.
